# IST display and signal charts — release 0.9.0

Deployed 5 October 2026. Interface dates use `Asia/Kolkata` with explicit 12-hour AM/PM and IST labels, including source/publication/expiry times, journal decisions, notifications, invitations/audit, chart axes/crosshairs, market close/seed labels and research display dates. Browser timezone does not determine the display. Canonical epoch timestamps, exported evidence, UTC exchange boundaries, strategy rules and risk arithmetic remain unchanged.

**Inspect signal** in Overview or Signal journal opens a chart with completed Binance 1H candles, a marker on the signal's source candle, original entry/SL/target price lines, EMA20/EMA50/SMA200 and the ATR14 pane. Exact frozen levels are also shown as text. Default indicator lines can be toggled. Auto-scaling includes the saved risk levels. The marker identifies the candle that generated the signal; the separate source-close timestamp identifies when it completed. It does not represent an exchange fill.

The chart refreshes from the backend every ten seconds while the detail dialog is open; closing it cancels polling. These are **completed candles**, consistent with the existing market chart, rather than unfinished candle/tick prices. Source context returns at most 169 retained bars (96 before the source, source itself, up to 72 after); Latest candles returns the latest 120. Both use stored candle/snapshot pairs, never browser indicator arithmetic. Removed coins can retain readable historical signal context; live status still requires fresh validated market data. Missing source candles have no fabricated marker. Stale/offline or withdrawn sources are labeled, and failed integrity blocks the chart. Responses must match the saved signal ID, symbol and plan hash.
